================================================================================
PRACTICAL 12: Event Management CRUD & File Upload
================================================================================

OVERVIEW:
This practical demonstrates building an Event Management module with file upload
capabilities for uploading event posters securely to the server.

KEY FEATURES & OBJECTIVES:
1. Full CRUD functionality for adding, editing, viewing, and deleting events.
2. Server-side file validation for poster image uploads (restricting file types like JPEG/PNG and file size).
3. Secure image renaming and storage in dedicated upload directories.
4. Clear frontend feedback using success and failure alerts.

TECHNOLOGIES USED:
- PHP File Handling & Form Processing
- MySQL Database
- HTML5 File Inputs / CSS Framework (Bootstrap/Tailwind)
